INPUT EXPLAINER

What does one input row contain?

The selected row is one feature-engineered snapshot for one machine at one point in time. The champion model scores this row independently.

Why only one row?

The deployed tabular champion does not fetch earlier raw records. Historical context has already been summarized into calculated features inside the selected row.

Direct measurements

Voltage, rotational speed, pressure and vibration are sensor readings measured at the observation time.

Calculated features

These include 3-hour and 24-hour rolling means and standard deviations, error counts from the preceding 24 hours, and days since each component was maintained.

Machine context

Machine age and model category provide additional context. The machine ID and observation time are used for traceability, not as model features.

To inspect every value sent to the model, use “Show all” in panel 04, “Observation features”.
